T2の変更と独立レビューの境界

決定と状態

  • ユーザーが選択・確認した方式は 無接着、全パーツ取り外し／再組立可能 です。
  • T1の接着方式は却下。承認待ちの候補ではありません。046a48e は履歴比較用の基準だけです。
  • 接着剤・テープ・熱かしめ・溶着は使いません。追加購入金具も不要です。
  • T2はデジタル試作。実物嵌合、印刷ねじの耐久性、保持力、転倒、手での作業性は未検証です。
  • 独立保持レビューは pending_coordinated_review。本変更記録は独立承認ではありません。

変更理由

小さな色部品を位置決めだけに頼る構成では、全パーツを可逆的に保持するという選択を満たせません。 T2では前後の正の止め面を持つフランジ捕捉に変更し、消耗し得る印刷ねじも個別交換可能にしました。 きつい摩擦、弾性ラッチ、不可逆な固定で小部品を保持する方式ではありません。

同じ独立レビュアーからのMEDIUM是正 / T2-R1

同じ独立レビュアーからHIGH/CRITICAL指摘はなく、次のMEDIUM 2件が返りました。 是正を実施・記録することと、是正後の独立受容は別です。pending_coordinated_review を維持します。

  1. 印刷接地。 旧T02 / CAPTURE-FRAMEは4本の背面ボスだけが接地し、主パネルがZ8 mmから始まっていました。 この2マスターだけをX軸180°回転し、前面をベッドに向けた提供STL・個別STEPへ変更します。 提供物は方向設定済みで、使用者がもう一度回転する指示ではありません。他部品の印刷姿勢は変更しません。 print_rotation_deg_xyz と逆の組立配置を記録し、接地 と 完成状態の不変性 を別々に確認します。
  2. 押し棒の全形状。 全EJECTORを瞳と一緒に9.5 mm進めると、虹彩との共通体積は約0.8112 mm³になります。 工具は初動のみ最大3.5 mmで止め、露出した後ろのフランジをつまんで残りを引き抜く手順へ限定します。 押し棒で最後まで押し出しません。全工具の初動0..3.5 mmの検査と危険な過大押しの反例を保存し、 両動画・字幕・tool-access図にも停止と把持への切替を示します。目・Mの解除順は変更しません。

これらの証拠は assembly.json と上記の印刷姿勢JSONへ統合します。 実物の印刷、手の届きやすさ、ねじ寿命、転倒は依然として未検証です。

レビューに渡す機構上の論点

  1. 前後の止め面。 通常部品の前面 8n−2.4、開口 8n−2.0、背面フランジ 8n−0.4 mm、 厚1.6 mm。前枠6.4 mm・ポケット1.8 mm・裏蓋当たり面Z=−0.2 mmを同時に確認。
  2. 入れ子の保持と解除。 白目／虹彩／瞳のフランジ下面Z=0 / −2 / −4 mm、白バッジ／Mは0 / −2 mm。 対応する蓋ポケットと正の当たり、先行部品を除いた後方0.2 / 1 / 4 / 12 / 24 mmの経路を確認。
  3. 真のねじ形状。 ピッチ3.2、谷径8.8、外径11.2、根元幅2.8、山頂幅0.4 mm。 掛かり9.6 mm（3回転）、雌深さ11.2、半径隙間0.3、追加軸方向余裕0.15 mm。 螺旋山が円筒に退化していないこと、純引抜き1.6 mmの衝突と回転連動時の解除を別々に確認。
  4. 押し棒と作業姿勢。 短い剛性先端1.6 × 2.4 mmだけでなく全工具を使った初動0..3.5 mmの隙間、 最大3.5 mmで工具を止めてフランジをつまむ条件と、 2個のASSEMBLY-RESTによる外側リム支持。顔の突出部に荷重を掛けない前面下向きの組立を説明。
  5. 試験と交換。 本番関数で作ったTHREAD-C40から実物T04を試す。 CAPTURE-FRAME/COVER＋実物IN-W-1x1＋T04で、全模型より先に捕捉と取り外しを試す。

独立レビュアーには同じT2のカタログ、保持回帰テスト、native/meshes/assemblyの検査JSON、 図面目録、Assembly / Disassemblyの両シーン、両MP4・両字幕、公開ファイルhashを渡します。 印刷接地・逆配置の不変性・全工具の初動上限の証拠も、同じ製造是正版へそろえます。 動画の尺・フレーム数・fpsは各々の検査メタデータから取得し、ソースへ固定値を転記しません。 T1の証拠や別スナップショットのメディアを混ぜません。全対数は現行78個なら3003組です。

承認権限と未検証範囲

統合担当だけが、共通部品と元の3案を扱った同じ独立レビュアーによる確認後、 independent_retention_review: accepted_digital_only を設定できます。 ソース更新担当・カタログ生成・サイト公開処理は、この値を付与しません。 ユーザーの方式確認も、独立レビューの代替ではありません。

ローカルChromeは新しい専用プロファイルでDevTools接続前にクラッシュし、 ブラウザー検査 は環境起因でblockedです。 librsvgによるSVGプレビューやソース回帰の合格は実ブラウザー検査の合格ではありません。 統合担当による別の正常なChrome環境での検査を残し、新しいブラウザーpassを主張しません。

デジタル受容後も、印刷誤差、ねじの摩耗、clutch、手指の到達性、転倒・衝撃、長期安全性は別の物理試験です。 physical_fit_tested: false を維持し、測定していない重量・印刷時間・耐久回数を作りません。 詳細は 検証範囲、可逆な作業手順は 作り方 を参照してください。
