# Copilot Brick Display

ブロック風の卓上オブジェを、Bambu Lab P1S と PLA で製作するための個人制作プロジェクトです。
電子部品は使用しません。

**現在の状態：設計中。製造用データの完成、実物との嵌合確認、試作完了を意味しません。**

## 設計する3案

寸法は台座を含む目標値です。幅・奥行き・高さの順で記載しています。

| 案 | デザイン | 目標寸法 |
| --- | --- | --- |
| A / Mini Relief | 小型・薄型のレリーフ | 144 × 64 × 約150 mm |
| B / Desk Classic | 参考写真に近い標準型 | 192 × 80 × 約200 mm |
| C / Display Sculpt | 厚みのある立体展示型 | 240 × 112 × 約250 mm |

市販ブロックとの接続寸法を維持するため、STLを一律に拡大・縮小するのではなく、
ブロックの数と配置でサイズを変える方針です。

## 予定する成果物

- 各案のFreeCADネイティブ完成モデル、STEP、印刷用STL
- 寸法図、色別部品表、嵌合テスト部品
- P1S・PLA・0.4 mm / 0.2 mmノズル向けの印刷案内
- 印刷、部品確認、試し合わせ、組み立て、完成確認までの日本語手順
- Blenderネイティブシーンと組み立てアニメーション
- 3案の比較、3D表示、図面、動画、ダウンロードをまとめたGitHub Pages

## 制作上の境界

本プロジェクトは非公式の個人制作モデルであり、LEGO社等による認定製品ではありません。
接続部は設計上の候補です。PLAと実物ブロックの保持力、着脱性、寸法公差は、
本体より先にテスト部品を印刷して確認する必要があります。無理に押し込まないでください。
小さな部品を含むため、子ども向け玩具としての安全性を保証するものではありません。

参考写真そのもの、私有の作業履歴、認証情報は公開しません。
要件、機械設計、製造条件、独立レビューを分ける進め方は、
[AI Hardware Engineering Team](https://github.com/ktanino10/ai-hardware-engineering-team)
を参考にします。元プロジェクトの電気回路やRev5設計は変更・移植しません。
