# Copilot Brick Display

**公開プライバシー更新中です。個人向けの完成データ配布は一時停止しています。**

[現在の公開状態](https://ktanino10.github.io/copilot-brick-display/)を確認してください。
旧版の個別メッセージを含むCAD・画像・動画・アーカイブは、現行配布から取り下げています。
公開デフォルトを`YOUR-USERNAME`などの明確な仮表示へ変更し、
個人設定をgit管理外の入力と分離して、実際のCAD・描画・文書・ダウンロードの一致を確認してから再公開します。
ファイル名の変更や画像上の文字隠しだけを匿名化とは扱いません。

## 維持する設計

通常A/B/Cの5段黒台座、8 mmピッチ、独立した前面銘板・右ロゴ、無接着での着脱、
上下へ大きく広がる3D表示を維持します。別のキャラクター版は、
個人識別子を除く範囲以外に新たな設計変更を加えません。
実物の嵌合・保持力・PLAの耐久性・強度・転倒は未試験です。

## 小さく試す手順

[7個を段階的に試す案内](docs/trial.ja.md)は保存しています。
別試験で観察された扱いにくさや穴の閉塞を参考にしますが、原因や合格補正値を転用せず、
既存の実部品を無変更で選ぶ方針です。外部の写真・動画・形状・モデルライセンスは複製していません。
公開配布の再開までは、未完成の生成物を製作版として扱わないでください。

## 履歴と権利

管理できる公開履歴・参照・配布物の清掃も進めています。
既存fork、ダウンロード済みコピー、外部キャッシュ、GitHub側の到達不能オブジェクトまで
完全に消去できる保証はありません。権限で処理できない残存事項は別に報告します。

これは非公式の個人制作プロジェクトです。GitHub・LEGO・Bambu Labの公認商品ではありません。
包括的な再利用ライセンスは未設定です。依存物のnoticeと権利条件は維持します。
