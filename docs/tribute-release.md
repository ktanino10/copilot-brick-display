# 別作品 Character Tribute の状態

`projects/character-tribute/`は、3つのブロック模型とは別の、赤い帽子・青いつなぎ・黒い猫風の
自作段差レリーフです。共通の交換式メッセージと8 mmピッチのドックを再利用しています。

**接着案は不採用です。ユーザーの明示的な選択は「接着剤を使わず、すべて取り外せる構造」です。**
小さな色レリーフも対象で、承認待ちではありません。旧候補の2.4 mm角ピンと2.8 mm角穴は
位置決め用であり、クランプ・スナップ保持ではありません。接着を省くだけでは要求を満たせないため、
保持・解除構造から再設計しています。

無接着で組み立てるA / B / Cの説明、部品数、印刷セットとは混ぜていません。
旧版の製作ダウンロードは公開サイトから除去しました。履歴中の旧CAD・メッシュ・検査記録は
**不採用となった実験の資料**であり、現在の製作版ではありません。
新しい保持・解除・組立と全成果物の一致を、同じ独立レビュアーが再確認した後に適合版のみを差し替えます。

原写真は公開していません。実物の嵌合・保持力・接着性能・耐久性・転倒は未試験です。
この追加作品の独立レビューは[機械レビュー記録](../validation/mechanical-review.md)の別スコープに記載しています。
