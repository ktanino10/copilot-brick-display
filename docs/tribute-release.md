# 別作品 Character Tribute の状態

`projects/character-tribute/`は、3つのブロック模型とは別の、赤い帽子・青いつなぎ・黒い猫風の
自作段差レリーフです。共通の交換式メッセージと8 mmピッチのドックを再利用しています。

**現時点では追加作品の製作リリースを保留しています。** 色パーツの位置決めは
2.4 mm角のピンと2.8 mm角の穴で、クランプ・スナップ保持ではありません。
複数の色パーツの保持に少量の接着を前提とする候補であり、その採用に対するユーザーの
明示的承認は、この公開記録ではまだ確認していません。
接着を省くだけで無接着版になるわけではありません。

無接着で組み立てるA / B / Cの説明、部品数、印刷セットとは混ぜていません。
追加ディレクトリにあるCAD・メッシュ・検査記録は**設計候補とデジタルレビュー用の資料**であり、
製作を承認したという表示ではありません。台座と文字カードの接続は無接着ですが、
その事実を色レリーフ全体の保持方法と混同しないでください。

原写真は公開していません。実物の嵌合・保持力・接着性能・耐久性・転倒は未試験です。
この追加作品の独立レビューは[機械レビュー記録](../validation/mechanical-review.md)の別スコープに記載しています。
