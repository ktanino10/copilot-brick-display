これは成人向けの屋内用卓上オブジェです。電子部品、モーター、電池、配線、接着剤は使いません。
**デジタル設計は用意されていますが、実物の嵌合・保持力・耐久性・転倒しにくさは未試験です。**
市販LEGOへの互換保証、玩具の安全認証、Bambu Labによる認定を意味しません。

**2026-09-19の試作手順追記：** 別の小型試験で「扱いにくい・穴が塞がる」という失敗が報告されています。
原因や補正値は未確定で、この模型の成功例ではありません。
まず[7個の現行実部品を段階的に試す手順](trial.ja.md)へ進み、入口・屋根のレイヤープレビューと手での着脱を確認してください。
**閉塞・つかみにくさ・着座不良があれば全数印刷を止めます。** 既存形状・8 mmピッチ・承認済み外観は変更していません。

印刷順は組立順ではありません。Bの1段目は `B-black-02.3mf` のslot 3 → `B-001` です。

## 別PCで、色別に印刷する

**手順更新：`separate-color-2026-09-19`／文字改訂2026-09-22。対象は公開の汎用版 `5.0-legible-plaques` です。**
A/B/Cのどれを印刷するかは、ここで**1案だけ選んでください**。サイトで最初にBが表示されても、Bを選択済みという意味ではありません。
公開の銘板は`USER`という短い仮表示です。実プロフィールへのリンクではありません。個人宛の銘板ファイルをこの公開セットへ混ぜません。
個人ファイルの転送・一時公開は別に判断する事項です。削除後も履歴・cache・第三者コピーに残る可能性があり、
この手順のために個人データを公開し直す必要はありません。

`plates.zip`には`manifest.json`と複数の汎用3MFが入り、**各3MFが1回分の候補配置**です。
配布の`plates.zip`そのものをスライサーへ読み込むのではなく、展開した3MFを1つずつ使います。

**3MFは形状・配置だけです。NOT_SLICEDで、P1S設定入りBambu StudioプロジェクトでもG-codeでもありません。**
STL方式と3MF方式は代替です。**同じ部品の3MFとSTLを両方読み込むと二重配置**になります。
別案のSTLや、別案・別プレートの3MFを同じプレートへまとめて足さないでください。

### 実機の設定を合わせる

1. Bambu Studioで、実際に使う **Bambu Lab P1S／装着済みノズル径** に合うプリンタプリセットを選びます。
   0.2 mmを装着しているのに0.4 mm設定を使う等の不一致があれば止めます。合う設定がない場合も別機種で代用しません。
2. 実際のPLAの銘柄・色、プレート種類、処理プロファイルを選びます。この配布物から実機の設定を推測しません。
   下記の0.4 mm本体／0.2 mm文字という案内は未検証のbaselineで、今回の実スライス成功値ではありません。
3. 最初は`FIT-M-D470.stl`と`FIT-F-CP12.stl`を**各1個**読み込みます。
   mm・倍率100%、提供された印刷方向、個数、ベッドへの接地を確認します。通常受けは穴側を下、スタッドは上です。
4. 実機設定でスライスし、初層の穴入口、内部ブリム／サポート、屋根のブリッジとリブ、細い突起の経路を
   [段階試作のプレビュー手順](trial.ja.md)に沿って確認します。入口の閉塞や欠落、分からない警告があれば印刷しません。
5. 使った設定を配布物と別名のローカルBambu Studioプロジェクトへ保存します。
   時間・フィラメント量はこの実スライスの表示結果だけを記録します。設定入りの実プロジェクトは、まだこちらでは受領・照合していません。
6. プレビューと実機条件を確認してから、Bambu Studioまたはプリンタの通常の操作で印刷します。
   本プロジェクトはプリンタへ自動送信したり、未確認のG-codeを提供したりしません。

試験がうまくいかなければ先へ進みません。**0.2 mmノズルにするだけで穴詰まりが解消するとは限りません。**
初層・支持材・流量・温度・穴径を原因不明のまま一律変更せず、現物とスライスを照合し、1条件ずつ記録します。

### 白い文字・白いロゴは「別の白部品」ではない

**文字とロゴは、黒い支持体に白い盛上りがつながった一体のSTLです。白部分だけを別体で刷って組む方式ではありません。**
色別に本体を印刷しても、この2部品には途中の黒→白切替が必要です。AMSなしで行う場合は手動交換を設定します。

| 選択案 | 銘板：黒→白の専用3MF | ロゴ：黒→白の専用3MF |
| --- | --- | --- |
| A | `A-black-to-white-z2p4-01.3mf`（`NP3-TEXT-A`×1） | `A-black-to-white-z2p8-01.3mf`（`NP3-LOGO-A`×1） |
| B | `B-black-to-white-z2p4-01.3mf`（`NP3-TEXT-B`×1） | `B-black-to-white-z2p8-01.3mf`（`NP3-LOGO-B`×1） |
| C | `C-black-to-white-z2p4-01.3mf`（`NP3-TEXT-C`×1） | `C-black-to-white-z2p8-01.3mf`（`NP3-LOGO-C`×1） |

この汎用3MFには**一時停止（Pause）も色替え命令も自動設定されていません**。
ファイル名とmanifestの高さは、設定すべき位置を示す案内です。開くだけで二色にはなりません。

1. 銘板またはロゴの専用3MFを1つ開き、平らな裏面をベッド、文字／図柄を上にしたまま黒PLAで始めます。
   倍率100%、部品Z=0を保ち、他の黒部品を同じプレートへ加えません。
2. Bambu Studioで実ノズル・PLA・プレートを選びスライスします。文字・図柄には0.2 mmを推奨しますが、線の連続性はプレビューで確認します。
3. **銘板はZ=2.4 mmまでの黒い支持体が終わった直後、次の白い文字層を出す前**に止めます。
   **ロゴはZ=2.8 mmまでの黒い支持体＋円形パッドが終わった直後、次の白い図柄層を出す前**に止めます。
   初層高・可変層高によって層番号は変わります。`2.4÷層高`のような固定番号ではなく、
   プレビュー上の黒地の最終層と、最初の盛上り経路の間で決めます。
4. プレビューのレイヤースライダーで、その**次の盛上り開始層の直前**へ一時停止を追加します。
   Bambu Studioのバージョンに応じたメニュー（通常は対象レイヤーの右クリックから「一時停止を追加／Add pause」）を使い、
   一時停止が実際に挿入され、白い経路より前で止まることを再確認します。位置や操作が分からなければ開始しません。
5. 印刷がその位置で停止したら、プリンタの通常のフィラメントunload／load手順に従って黒から白へ交換し、
   残った黒が混ざらないよう排出を確認してから再開します。プレートや造形物を動かさず、高温部へ触れず、
   自動動作前には手や工具を退避します。未確認の手書きG-codeは使いません。
6. 白いレリーフは**文字1.2 mm、右ロゴ0.8 mm**です。最後まで印刷して十分冷めてから外し、欠け・文字欠落・裏面の反りを確認します。

Pause／交換／再開の初回実機確認はまだ行っていません。P1Sの標準操作に従い、
別機種のタッチスクリーン手順や未検証のM600等のカスタムG-codeを流用しません。

**途中の色替えなしで白文字／白ロゴも完全別体にしたい場合は設計変更です。**
現状データを勝手に分割したり、塗装前提へ読み替えたりせず、別途相談してください。

### 印刷する順番と、個人向けファイルの扱い

`FIT-M-D470`×1＋`FIT-F-CP12`×1 → 必要な`NP3-FIT` → 実ブロック4個 →
keeper1個＋選択案の同一台座端部2個 → 選択案の5段台座と前面 → 顔の少量バッチ、の順です。
色ごとの本体プレートを一気に全部刷る前に、各段階で入口・つかみやすさ・着座・保持を確認します。
閉塞、強い力、つかめない、割れや白化があれば止めます。7個試作を全体合格とは扱いません。

ここで配布するのは汎用版だけです。**個人宛のファイルを一時的にpublicへ置く操作は、この手順には含めていません。**
個人用入力・生成物はprivateのまま保管し、転送方法と残存リスクを確認してから別に扱います。
公開Issueの例にも実recipient名を入れません。

**別途、同じ取付け仕様の個人向けB用銘板1枚を受け取った場合だけ**、汎用の`NP3-TEXT-B`をその1枚に置き換えます。
`B-black-to-white-z2p4-01.3mf`と`NP3-TEXT-B.stl`の両方を印刷対象から外し、交換用ファイルのSTLか3MFのどちらか一方を1個だけ使います。
右ロゴ用の`B-black-to-white-z2p8-01.3mf`や、本体の黒7・シアン2・マゼンタ2・緑1のプレートは変更しません。
交換品も黒い支持体＋白い一体文字なら、2.4 mm後の手動色替えが必要です。完成Bの総部品数を増やす追加部品ではありません。
別サイズや取付けが一致しない銘板には、この置換手順を適用しません。個人ファイルの所在・表示内容をこの公開ガイドへ転載しません。

## 1. 用意するもの

- Bambu Lab P1S、選択したノズルに合うBambu Studioのプリンタ設定。
- 普通のPLA：ブラック、シアン、マゼンタ、グリーン、ホワイト。AMSは不要です。
- 0.4 mmノズルを本体の基本に、0.2 mmノズルを文字銘板・ロゴ・嵌合の改善候補に使います。
- ノギス、平らな机、部品を入れる色別トレー、やわらかい布。必要なら細目のやすり。
- 傷めてもよいという意味ではなく、状態がよく、変形していない市販の小さな2×2／2×4ブロック。

PLAは市販ブロックで多く使われるABSと性質が異なり、割れ・白化・熱変形に注意が必要です。
小部品や破片を子ども・ペットの手の届く場所に置かないでください。組立品を口に入れないでください。
**強く押す、こじる、打撃を加える、熱で無理に合わせる作業はしません。**

別々の色替えプレートで印刷します。他の黒部品と一緒に刷って途中で白に替えないでください。
`assembly.json`、組立PDF、サイトの工程表示は同じ部品配置から作っています。

**大きさを変えるためにSTLを拡大・縮小しないでください。** 8 mmピッチが変わり、市販品と接続できなくなります。
他の大きさが必要なときは、ブロック数・配置を変更して再生成します。

## 3. 本体より先に、オス・メスの小片を印刷

最初から台座や本体を一括印刷しません。`fit-coupons.zip`の部品を1候補ずつ印刷し、
ファイル名が分かる袋やトレーで保管します。取り違えないよう、同時に混ぜないでください。
まずBambu Studioで実装ノズルとプリセット、材料・プレートを一致させ、
[入口から屋根までのレイヤー確認](trial.ja.md)を行います。
0.2 mmノズルへ替えるだけで閉塞が直るとは限りません。

| 系列 | ファイルID | 変更しているもの |
| --- | --- | --- |
| オス | `FIT-M-D470` / `D480` / `D490` | スタッド外径4.70 / 4.80 / 4.90 mm |
| メス | `FIT-F-CP12` / `CP08` / `CP04` / `CP00` / `CM04` | 半径方向の設計クリアランス +0.12 / +0.08 / +0.04 / 0.00 / −0.04 mm |

負の値は意図的な干渉候補です。最初はメス`CP12`、オス`D470`というゆるい候補から始めます。
形状が似ていてもオス寸法の補正とメス側の補正は別物です。
公称4.8 mmをすべての実物の実測値とみなさないでください。

1. 以下の「印刷の初期設定」で1組を印刷します。完全に冷ましてから外します。
2. 底のつぶれ、糸引き、穴をふさぐブリム、屋根の垂れを観察します。異常があるものは接続試験に使いません。
3. スタッドの円筒部をX・Y両方向で測ります。先端の面取り部分を測らないでください。
4. 4×2片の本体は31.8×15.8 mm、中心間隔は8 mmです。4本のスタッドの両外端間隔から平均外径を引き、3で割るとピッチを確認できます。
5. **印刷オス → 市販メス**を軽く合わせます。次に**市販オス → 印刷メス**を別々に確認します。
6. 両方の組合せがよければ、最後に**印刷オス → 印刷メス**を確認します。
7. 有望な設定を3個ずつ印刷し、色・ノズル・PLAが変わっても同じ結果になるか確認します。

測定表を[fit-log.csv](../site/downloads/fit-log.csv)に残します。機器の精度・測定のばらつきが候補の差より大きいときは、
「0.04 mm違うからよくなった」と結論しません。

### 銘板・ロゴのキー溝も別に試す

`NP3-FIT-PLAQUE`と`NP3-FIT-SOCKET-C25`から始め、C20、C15へ段階的に比較します。
これは本番と同じ裏側の広がり・2.4 mm厚・角度・座面を使った短い試験片です。
銘板とロゴは上から入れ、前・横・下へは形状で抜け止めします。試験片が滑っても、
5段の溝の位置合わせと幅の長い部品の反りは別問題なので、採用した設定で本体用銘板・ロゴを1個ずつ試します。
台座の最前列8 mm帯はこの溝のためにスタッドと底面接続を予約・除外しています。
市販品との接続試験は通常ブロックや台座の2列目以降で行い、前面モジュールを市販品へ無理に接続しません。

### 次へ進む目安（未検証のスクリーニング条件）

- 軽い指の力で最後まで座り、見える段間の隙間が約0.10 mm以下。ぐらつかないこと。
- 小さな組合せを布の上で10秒そっと反転しても外れず、10回の穏やかな着脱で白化・ひび・欠けがないこと。
- 市販部品に傷や変形が出ないこと。引き抜く際に工具やこじりが必要なら不合格です。
- Aの3.2 mmプレートやキーパーも1点先行し、実測したスタッド高さと屋根下面の間に0.10 mm以上の余地が残ること。
- 大きな台座の四隅の浮き・がたつきが平面上で約0.30 mm以下であること。

これは荷重定格や安全基準ではありません。**組立全体を反転する試験ではありません。**
ゆるくても、きつくても、本体に進まず設定を調整します。

### couponの次は、実際のブロックを少量だけ

[少量試作ZIP](../site/downloads/trial-subset.zip)には、現行STLそのままの代表2×2・2×4、keeper、
A/B/Cの台座端部を収録しました。**1案の小BOMだけを選び、4個の実ブロック→keeperと同一台座端部2個の計7個**を段階的に試します。
全案のBOMを合算しません。既存の公差couponは同梱し直さず、上の`fit-coupons.zip`を再利用します。
7個はつかみやすさ・下面閉塞・初期着脱の確認で、5段全幅や大銘板の保持合格ではありません。
その後、選択案の実5段台座と銘板／ロゴ／3個のkeeperを、顔の全数より先に試します。

## 4. 合わないときの補正と再生成

まず、実際に使ったスライス設定入りプロジェクトと現物の該当位置を照合します。
原因不明のまま、全穴径・XY補正・流量・温度を一律変更しません。小穴を一つずつ削る作業も完成キットの前提にしません。
初層、支持材、ブリム、ブリッジ、形状を分けて確認し、1条件ずつ記録して試します。
底のつぶれや屋根の垂れが確認できた場合は、まずその造形条件を検討します。0.2 mmノズルも比較候補ですが、解決の保証ではありません。
以下の寸法補正は、形状と印刷原因を切り分けた後の候補です。

- 印刷スタッドが大きすぎる：`interface.stud_diameter_correction`を小さくします。
- 市販スタッドが印刷メスにきつい：`interface.female_radial_clearance`を大きくします。
- 保持が弱い：試験片で一段ずつ逆方向へ試します。負のクリアランスをいきなり本体へ使いません。
- 銘板・ロゴだけきつい：まず5段の整列と反りを確認し、試験片で`message.clearance`を小刻みに増やします。
  これはキー溝の側方遊びです。文字やロゴの大きさ、8 mmピッチは変更しません。

値は[design/parameters.json](../design/parameters.json)だけで変更します。
たとえばメスの半径クリアランスを`0.04`から`0.08`へ変えることは、穴の直径を一律0.04 mm変える操作ではありません。
内壁・チューブ・ポストを同じ拘束式で再計算します。[再生成手順](rebuild.md)でCADから作り直し、
**新しい試験片で再確認してから、同じリビジョンの本体を印刷**します。古いSTLと混ぜないでください。

## 5. P1S / PLAの印刷初期設定

以下は実機で検証していない出発点です。温度・冷却・流量は、実際のPLA銘柄と使用プレートに対応する
Bambu Studioのプリセットを基準に調整します。AMSがなくても色ごとに印刷できます。

| 項目 | 0.4 mmノズル：本体の基本 | 0.2 mmノズル：細部・文字・再試験 |
| --- | --- | --- |
| 層高 / 初層 | 0.20 / 0.20 mm | 0.10 / 0.20 mm |
| 線幅の初期値 | 0.42 mm | 0.22 mm |
| 壁ループの要求値 | 4 | 7 |
| 上面 / 底面ソリッド層 | 4 / 4以上 | 8 / 8以上 |
| 外壁速度の上限候補 | 30 mm/s | 20 mm/s |
| ブリッジ速度の上限候補 | 20 mm/s | 15 mm/s |
| 残る中実領域のインフィル | 15–20% gyroidから | 同左 |
| サポート | 基本なし。嵌合穴内に自動で入れない | 同左 |
| 外側ブリム | 大きな台座で6 mmを候補に。小片は必要時のみ | 同左 |

CADの壁はおよそ1.46 mm、屋根は通常1.6 mm、薄いプレートだけ1.0 mmです。
壁ループ数の指定だけでは材料が入った証明になりません。スライスのプレビューで壁、ポスト、チューブ、
屋根、文字が連続しているか確認します。細い壁は可変線幅の候補も比較します。
インフィル設定でCADにある空洞を埋めることはできません。

通常ブロック・台座部品・キーパーは**穴側をベッド、スタッドや平らな上面を上**に置きます。
内部リブは8 mmごとで、屋根の直交方向の主な無支持区間は最大6.8 mm、チューブの内穴は3.2 mmです。
それでもブリッジの垂れは実機で確認が必要です。最初の屋根層の橋渡しをプレビューで確認し、
失敗したら流量・冷却・速度・方向を調整して試験片へ戻ります。
薄い屋根に後から層を足すだけでは、最初の層の垂れは直りません。

台座の外形＋左右6 mmブリムはA 155.8×75.8、B 203.8×91.8、
Cは**1枚につき131.8×123.8 mm**です。公称256×256 mm内に収まる寸法ですが、
プレートの実際の除外領域・スカート・校正線・ヘッド干渉はBambu Studioで別に確認します。
中央寄せで1枚ずつ試すのが基本です。Cの2枚を無理に1プレートへ詰め込みません。
印刷時間・重量の実測値や検証済みG-codeは提供していません。

### 大きい2行銘板と右ロゴ

`NP3-TEXT-A/B/C`と`NP3-LOGO-A/B/C`は、どちらも**平らな裏面をベッド、文字／図柄を上**にしたSTLです。
0.2 mmノズルを推奨します。黒PLAで始め、銘板は**2.4 mm層を終えた直後**、ロゴは
**2.8 mm層を終えた直後**に一時停止して白PLAへ手動交換します。白レリーフは文字1.2 mm、右ロゴ0.8 mmです。
これは設計境界で、固定の層番号ではありません。初層・可変層高を含む実プレビューで最初の白経路の前にPauseがあることを確認します。
AMS不要・別々の色替えプレートで印刷します。画像だけの文字・テクスチャではなく、本物の立体形状です。
元の図柄画像は公開していません。黒い背板が白い図柄全体を支えるため、小さな白い尾や耳を別部品で貼り付けません。

| 案 | 銘板の裏側幅 × 高さ | 主文 / URLの文字高 | 右ロゴの円径 / キャリア幅 |
| --- | --- | --- | --- |
| A | 102 × 40 mm | 10 / 10 mm | 28 / 32 mm |
| B | 142 × 40 mm | 12 / 10 mm | 36 / 40 mm |
| C | 182 × 40 mm | 14.5 / 10 mm | 40 / 48 mm |

主文はBold、URLはBlackです。孔・eの出口・字間を広げ、平行な正のストロークと材料neckも実CADから別々に測定しています。
小型Aの主文は幅内で材料を保つため異なる目標を使います。[各案の実測と限界](lettering.ja.md)を確認してください。
曲線の先端や数学的な角の全てに同じ幅があるという意味ではないので、スライサーで細部も確認します。
キー溝の裏側は広く、表側は各端2 mm狭い形です。印刷向きと斜面を勝手に反転しないでください。

銘板を全数刷る前に[文字の小試験片ZIP](../site/downloads/lettering-coupons.zip)から、
選んだ案の`GLYPH-A/B/C`を1個だけ使います。上に`aeod`、下に`gbo./R`があり、実銘板の字形を拡大縮小せず移したものです。
STLと3MFは代替なので両方読み込まないでください。平らな黒支持体を下、黒2.4 mm後に白1.2 mm。
孔・eの開口・dot/slash・細線の経路が残るか先にスライスで確認し、冷めた実物で閉塞・文字同士の橋・糸・欠け・荒れを観察します。
閉塞や白化があれば本体銘板を刷らず停止します。試験片は完成BOMに含まず、成功しても全体保持の合格ではありません。
0.2 mmノズルでのフィードバックを受けた形状案であり、0.2 mmにすれば成功する、糸引きや上面荒れが形状だけで直る、とは扱いません。
実設定入りBambu Studioプロジェクトは未受領です。実ノズル・PLA・初層・flow・冷却・速度等は一条件ずつ現物と照合します。

## 6. 色別に本体を印刷し、番号付きトレーへ

採用した設定で色ごとに印刷します。各BOM行は`部品ID × 色 × 数量`です。
一度に全部刷る前に、深いブロック、薄いプレート、キーパー、前面モジュールを1個ずつ実物で確認します。
完全に冷えたらプレートの説明に従って取り外し、外側ブリム・糸引きだけを丁寧に除去します。
スタッドやチューブを削りすぎると候補寸法ではなくなります。ひび・白化があるものは使いません。
ラベルは`A-001`などの**配置番号**と`BR-…`の**形状ID**を区別してください。

## 7. 下から、1段ずつ組み立てる

選んだ案の[サイトの工程表示](https://ktanino10.github.io/copilot-brick-display/#workbench)、
組立PDF、BOMを横に置きます。工程の平面図は**手前が図の下**です。
工程表の各配置番号はFreeCAD、Webの部品選択、Blenderの最終配置と一致します。

1. 黒台座の1段目を机に置きます。Cは最下段を2枚に分け、中央に0.2 mmの隙間ができるよう並べます。
2. 2〜5段目を番号順に積みます。各段は本物の独立部品で、継ぎ目が互い違いになる配置です。
   Cの中央継ぎ目も上の段がまたいで連結します。前側5段のキー溝が一直線になることを確認します。
3. 大きい文字銘板を左、ロゴを右のキー溝へ、それぞれ上から差し込みます。両方ともZ4〜44 mmの台座内に納まります。
4. 銘板の上止め用キーパー2個と、ロゴ用1個を、台座上の2列目のスタッドへ載せます。
5. 顔の本体1段目から指定の色・形状・位置へ上から載せ、緑の縦線、ゴーグル、頭頂まで進みます。
6. 各段の隙間、キーパーの保持、2行と右ロゴの位置、台座のがたつきと転倒しやすさを確認します。

銘板の文字は正確に以下の2行です。

> Same icon, New adventures<br>
> github.com/USER

2行目は仮表示で、実在の相手のプロフィールを示すものではありません。
別の文字へ変える場合は[公開forkとprivate入力を分ける手順](customize.ja.md)を先に読み、
非公開の値を公開Issue・PR・CAD・画像へ入れないでください。

交換時は該当モジュールのキーパーだけを、まず上へ6 mm程度外し、手前へ32 mm以上離して脇に置きます。
その後モジュールをまっすぐ45 mm以上持ち上げ、キー溝から抜いて手前へ取り出します。
文字とロゴは別々に交換できます。本体は後ろにあり抜去経路をふさぎませんが、実物でも軽い力で確認します。
全部分解するときは前面モジュールを外し、顔を上から逆順に、最後に台座を上段から外します。
完成品を持つときは**台座を両手で支えます**。頭、ゴーグル、銘板、ロゴ、キーパーを持ち手にしません。

### サイトの大きい上下分解表示

0%は実CADの完成配置です。初めにキーパーを解除してモジュールを上抜き・前へ分離し、
100%では下段を下へ、上段を上へ広げます。台座5段も対象で、各段の空隙は18.2 mm以上です。
表示中の外接範囲に合わせてカメラを調整し、向きは保ちます。これは説明用の移動で、物理的な分解保証や寸法変更ではありません。
上下の隙間は立体・正面・側面で確認してください。上面は上下の部品が投影上重なります。

## 8. 完成後の確認と困ったとき

平らな机の奥側で、台座の浮き、揺れ、前後左右への倒れやすさを軽く確認します。
落ちても被害のない低い位置で行い、押し倒したり振動を加えたりしません。
ぐらつく、自然に外れる、ひびが出る場合は飾らず、該当部品と設定を見直します。
棚の縁、直射日光、暖房器具の近く、車内には置きません。

| 症状 | 確認するところ |
| --- | --- |
| 最後まで座らない | 異物・ブリム・底のつぶれ・屋根の垂れ・実測スタッド高さ。無理に押さず試験片へ戻る |
| 硬すぎる | オス寸法とメスクリアランスを別々に確認。0.2 mmノズルも候補 |
| ゆるくて落ちる | 片側ずつ試験。保持を確認できる設定になるまで本体を積まない |
| 部品が余る／色が違う | 選択したA/B/C、BOMの色別数量、配置番号、工程を照合 |
| 台座が反る | プレート清掃・冷却・外側ブリム・PLA条件を再確認。Cは2枚のまま印刷 |
| 文字やロゴがつぶれる | 0.2 mmノズルで前面モジュールだけ再印刷。倍率変更ではなく線幅と層を確認 |
| モジュールが上へ抜ける | 対応するキーパーが装着され、スタッドの保持が確認できているか。きつい／ゆるい時は試験片へ戻る |

CAD・動画・自動チェックは、これらの実物確認を代行しません。
