## 写真観察と検証の境界

| 種類 | この記録が扱う範囲 |
| --- | --- |
| 本人報告 | 「いけているみたい」「土台が組み上がりました」という制作中の発言 |
| 写真観察 | 黒い台座の積層・継ぎ目、前面の空溝、右ロゴのみの装着、銘板と右ロゴの装着状態 |
| デジタル検証 | 公開版5.0の寸法・形状・干渉・数量・実データの一致。写真とは別の証拠 |
| 未測定・未確認 | 実際に使ったSTLハッシュ、設定入りBambu Studioプロジェクト、測定された嵌合・keeper保持力、完成品の強度・安全性・転倒・寿命 |

写真から「実際に台座と前面部品が作られた」と確認できても、
全150部品の組立完了、全5段を下から逐次撮影したこと、部品の着座寸法や保持力までは推定しません。
`NOT_SLICED`と既存のデジタル検証結果を、写真だけで実機合格へ変更する作業ではありません。
A/Cと公開の `github.com/USER` 文字版の物理試験も、別途必要です。

実ノズル・PLA・プレート・層高・flow・温度などを照合できる**設定入り実`.3mf`は未提供**です。
現物の使用条件を残すときは、個人情報を含む設定や写真を公開Issueへ置かず、非公開で扱ってください。
孔の閉塞、白化、割れ、強い力、着座不良があれば停止し、現物とスライスを一条件ずつ比較します。
