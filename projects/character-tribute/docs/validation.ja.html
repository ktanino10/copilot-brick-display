CADでは接着層の厚み・接着強度・樹脂のたわみ・手指の動き・プリンターの誤差を再現していません。 「干渉なし」は、ある隙間で保持する／着脱しやすい／壊れないという主張ではありません。 挿入経路は、開いた直線方向のスロットと指定した位置でのBRep検査です。全連続時刻の弾性・人間工学シミュレーションではありません。

均質な完全ソリッドの幾何学的重心は、およそX−0.002、Y3.961、Z67.500 mm。 支持多角形の最寄り辺までの投影余裕は44.039 mmです。 これは実際にスライスした充填率・密度・接着剤の重量を反映した値ではありません。 試験で測った重量・印刷時間・保持力・転倒角はありません。

実物で残る確認

  1. 使用PLA、ノズル、層高、温度、補正を記録して試験片を印刷。
  2. 市販品→印刷品、印刷品→市販品、印刷品同士の3方向で、軽い着脱・白化・割れ・摩耗を確認。
  3. 背板の長い差込部、台座の反り、カードの抜き差しを本番部品でも仮合わせ。
  4. 小色部品の接着を端材で確認し、完全硬化後の脱落・変色を確認。
  5. 完成品を平らな机で確認。机の端を避け、異常に傾く・ぐらつく場合は使わない。

結果が出るまでは physical_fit_tested: false として扱います。 寸法の元資料、FDMの候補補正、実物の測定結果を混同しないでください。
