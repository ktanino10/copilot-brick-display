補正するとき

STL全体の拡大縮小は禁止です。8 mmピッチ、カード、舌、ねじの全てが変わってしまいます。 まず反り・象の足・糸引きを解消し、必要なら parameters.json の該当寸法のみ変更して全データを再生成・再検査します。 溝は stand.slot_depth、ねじは screw.radial_clearance など、本番と試験片の同じ生成経路を使います。 共有インターフェースはこのT2では変更しません。将来変更する場合は共通正本と固定参照を一緒に更新する別の変更です。 カタログを手直しせず、補正後の版・数値と実測記録を残してください。

2. 色別の部品を照合する

カタログの category: assembly が完成品に入る部品です。色・ID・数量をCSVと照合し、トレイを分けます。 coupon と tool は別区分で、完成品には入りません。治具の必要数は tool_quantity を使います。 通常インサートは8 mmの複数セルを一体化したカセットです。図の投影三角線やセル境界で切り離しません。

通常インサートの一辺は、セル数をnとすると前面本体 8n−2.4 mm、開口 8n−2.0 mm、 背面フランジ 8n−0.4 mmです（縦横それぞれのセル数に適用）。フランジ厚は1.6 mm、 前枠厚は6.4 mm、後面ポケット深さは1.8 mm。名目の掛かりは片側0.8 mm、 横遊び0.2 mmが片側へ寄っても最小0.6 mm残ります。

局所Zは前向きを正とします。通常フランジはZ=0..1.6 mm、裏蓋の当たり面はZ=−0.2 mmで、 前方+0.2 mm／後方−0.2 mmに動くとそれぞれの止め面に当たります。 通常の微小な遊びは許容する設計で、きつい圧入で固定するものではありません。

3. 前面を保護して組む

T02の舌をT01の溝に一度まっすぐ仮合わせしてから、台座から外します。 2個のASSEMBLY-RESTを外側左右のリムに当てて、前枠を前面下向きに支持します。 支持位置の目安は前枠の局所座標x≈±76 mm、y=24..136 mm。顔・目の突出部は机や治具で押さえません。 前面を裸の机へ直接置かず、治具が安定していることを確認してください。 保存ネイティブと実治具STEPによる 支持姿勢の検査 では、 作業台上の治具の印刷原点を [-84, -136, 0] / [68, -136, 0] mmに置くと、 構造前面が机上12 mm、目などの突出部が最小約5.6 mm浮き、治具は前枠だけに接触します。 これは前枠の局所座標とは別の表現です。剛体CADの隙間の確認であり、実物の水平・反り・安定性は未検証です。

5. 完全分解と再組立

分解動画 と 日本語字幕 を参照してください。 同じ.blend内の別シーン Disassembly に、分解用の実キーフレームがあります。 各動画の尺・フレーム数は 動画検査JSON が正本です。

  1. 柔らかいトレイを用意し、カード、ドック、台座を必要に応じて取り外して作業空間を確保します。
  2. 前枠を支え、背面のねじ頭から見て反時計回りにT04を4本とも外します。ねじは回転と軸移動で抜きます。
  3. T03を後方へ外します。蓋が無い間、色部品は後方へ出られるので、必ずトレイ上で受けてください。
  4. 目は瞳→虹彩→白目、バッジはM→白の順です。通常インサートも含め、すべて後方へ取り出します。
  5. 指で後ろのフランジを持てない場合だけ、前枠を慎重にトレイ上で保持してEJECTORを指定の前面に当てます。 押し棒は初動のみ。接触開始から最大3.5 mm以内で工具を止めてください。 フランジをつまめる位置になったら、3.5 mmに達する前でも止めます。
  6. 工具を外し、露出した後ろのフランジを指などでつまみ、残りの距離を後方へ引き抜きます。 EJECTORだけで最後まで押し出しません。3.5 mm以内でつまめない場合は中止し、部品順・バリ・印刷誤差を確認します。 工具をさらに押したり、細い首をこじったりして解決しません。

EJECTORは先端1.6 × 2.4 mmの短い剛性押し棒です。弾性ラッチや、細い首をこじるレバーではありません。 上限3.5 mmは目・M・通常インサートを含むすべてのEJECTOR操作に適用します。必要な距離まで必ず押す指示ではありません。 上限と「その後フランジをつかむ」条件は parameters.json の release_tool に記録されています。 押し位置と先端回転はカタログ各配置の tool_target_xy / tool_tip_rotation_deg を正とします。 以下の目安は各部品中心からの相対座標です（前枠の局所xは右、yは上）。
